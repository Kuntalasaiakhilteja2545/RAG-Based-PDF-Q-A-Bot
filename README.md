# RAG-Based PDF Q&A Bot

A compact, production-oriented mini project that implements Retrieval-Augmented Generation (RAG) over PDFs using LangChain, embeddings, and a vector search index.

See file-by-file examples in the repo. Run `python ingest.py sample_data/example.pdf` to build an index, then `streamlit run app_streamlit.py` to open the demo UI.
